Check the file before you install it

A tool whose purpose is provenance should let you verify its own provenance. Both checksums above are the ones recorded in the release log at build time. Compare before installing; if a value differs, do not use the file and tell us.

Windows, PowerShell:

Get-FileHash -Algorithm SHA256 "$env:USERPROFILE\Downloads\oa_harvester-1.3.0-py3-none-any.whl"

Linux and macOS:

sha256sum oa_harvester-1.3.0-py3-none-any.whl

Before you start

Python 3.11
Notanda installs into an isolated environment of your own. No administrator rights are needed and nothing is written outside your user folder.
Your own OpenAlex key
Free, from openalex.org/settings/api. We do not hand out a shared key: the quota and the attribution are yours. Without a key the daily budget is much smaller.
A terminal, briefly
There is no installer yet and no double-click. Installation is a handful of commands, and the step-by-step instructions come with your access mail.

Where it has run

Stated the way we would want it stated to us — what is proven, and what is merely likely.

Linux
Release 1.3.0 built and installed, the offline test suite run against the built package, package contents verified file by file.
Windows
Release 1.3.0 installed and run twice: on 18 September on a separate machine with a clean install, and on 19 September on the maintainer's own machine in an existing environment. Both times a live run against real sources, with the wheel's checksum independently recomputed and confirmed on each machine. An unguided first-time install by a new user, following only the written instructions, has not yet been run.
macOS
Never run. Nothing here has been tested on macOS, and we would rather say so than let you find out.

The download is an unsigned file. Windows will warn you about that, and it is right to. Compare the checksum above — that is what it is for.

When something goes wrong

Write to beta@notanda.io and say where it stopped. A step that fails is useful to us; a step that was confusing is just as useful. Never send your OpenAlex key, and check that it is not visible in a screenshot before you attach one.
